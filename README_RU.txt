OCA Календарь — PWA для iPhone

Что есть:
- Календарь на русском языке.
- Основные фиксированные праздники OCA по гражданским датам Revised Julian Calendar.
- Расчет православной Пасхи и переходящих праздников для любого выбранного года.
- Основные многодневные посты и обычные среды/пятницы (с оговоркой о приходской практике).
- Кнопки «Чтения OCA» и «Святые дня» ведут на официальный oca.org.
- После установки как PWA основная оболочка и календарь работают офлайн.

КАК УСТАНОВИТЬ НА IPHONE
Для настоящей кнопки «На экран Домой» сайт должен быть размещен по HTTPS.
1. Разместите содержимое этой папки на любом статическом HTTPS-хостинге (GitHub Pages, Netlify, Cloudflare Pages и т.п.).
2. Откройте полученную ссылку в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
4. После этого OCA Календарь будет открываться почти как обычное приложение, без панели Safari.

Важно:
- Внутри приложения не копируется полный библейский текст OCA/NKJV; вместо этого открывается официальная страница OCA.
- Полный список всех святых на каждый день также остается на официальной странице OCA. Локально отмечены основные праздники.
- Для точных правил поста следуйте указаниям вашего прихода/духовника.
