OCA Календарь — версия 5.0

Что нового:
- Добавлен русский месяцеслов по «Азбуке веры».
- Для выбранной даты OCA приложение берёт ту же номинальную церковную дату по старому (юлианскому) стилю и переводит её в гражданскую дату, используемую календарём Русской Православной Церкви.
- Пример: 8 сентября 2026 OCA → 21 сентября 2026 гражданского календаря РПЦ (8 сентября ст. ст.).
- В отдельном блоке показываются праздники, святые и памятные события из верхнего списка ежедневного календаря «Азбуки веры».
- Переходящие праздники по Пасхалии не сдвигаются механически на 13 дней; сопоставление + старый стиль применяется именно к месяцеслову / неподвижному кругу.

Источники:
- OCA: oca.org
- Русский месяцеслов: azbyka.ru/days

Установка обновления:
1. Загрузить все файлы из этой папки в корень GitHub-репозитория поверх старых.
2. Commit directly to main.
3. Дождаться зелёной галочки GitHub Pages.
4. Полностью закрыть приложение на iPhone и открыть снова.
5. Внизу страницы должна быть указана версия 5.0.
